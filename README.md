# 훈민정음: 사라진 글자를 찾아라

한글날 학교 축제에서 사용하는 Three.js 교육용 웹게임입니다. 궁궐에서 글자 조각을 찾고, 자음·모음·가획·음절 조립 퍼즐을 푼 뒤 60초 퀴즈와 인증서로 마무리합니다.

## 실행

Node.js와 npm이 필요합니다. 이 프로젝트의 Vite 8을 실행할 수 있는 Node.js 버전을 사용하세요.

```sh
npm install
npm run dev
```

개발 주소는 `http://127.0.0.1:5188`입니다. 배포 파일을 만들려면 다음을 실행합니다.

```sh
npm run build
npm run preview
```

미리보기 주소는 `http://127.0.0.1:4188`입니다. `dist` 폴더 전체를 정적 호스팅에 올립니다. Vite의 `base: './'` 설정으로 파일 경로는 상대 경로를 사용합니다. `index.html`을 파일 탐색기에서 직접 여는 대신 HTTP 서버로 실행하세요. 서버 API나 데이터베이스는 없습니다.

## 조작과 흐름

- 이동: WASD 또는 방향키. 가까운 글자 발견: E.
- 시점: 탐험 화면 드래그.
- 모바일: 왼쪽 조이스틱과 오른쪽 발견 버튼.
- 퍼즐: 글자와 알맞은 대상을 차례로 선택. 가획 퍼즐은 획을 끌거나 선택 후 점선을 누릅니다.
- 퀴즈: 보기 선택 또는 숫자 1–4. 퀴즈 중 시간은 멈추지 않습니다.
- 도움말: 상단 `?`. 탐험 일시 정지: 상단 정지 버튼 또는 Esc.

탐험 → 자음 기관 연결 → 천·지·인 → 가획 → ‘한글’ 조립 → 복원 → 60초 도전 → 결과 → 인증서 순서입니다. 본편 8–12분은 안내용 권장 시간이며 실제 시간은 참가자마다 다릅니다.

## 점수

| 항목 | 점수 |
| --- | ---: |
| 글자 조각 5개 | 500 |
| 자음 5개·모음 3개·가획 7개, 각 200점 | 3,000 |
| ‘한’·‘글’ 완성, 각 500점 | 1,000 |
| 훈민정음 복원 | 1,000 |
| 본편 시간 보너스 | 최대 500 |
| 퀴즈 정답 | 문항당 100 |
| 연속 정답 보너스 | 5연속 100, 10연속 300 |

본편 기본 점수는 **5,500점**, 시간 보너스를 포함하면 **최대 6,000점**입니다. 원리 퍼즐 합계는 4,000점입니다. 시간 보너스는 `max(0, min(500, floor((720 - elapsed) / 12) * 10))`으로 계산합니다. 퀴즈 오답은 점수를 깎지 않고 연속 정답 수를 초기화합니다. 콤보 보너스는 15·25연속에 100점, 20·30연속에 300점처럼 반복됩니다.

## 학교별 설정

`src/config/gameConfig.ts`에서 학교 이름, 로고, 축제 모드, 퀴즈 시간, 순위 표시 수, 자동 복귀 시간을 변경합니다. 기본값은 퀴즈 60초, 오늘 순위 10명, 결과 화면 계열에서 미조작 30초 후 처음으로, 시작 화면 미조작 45초 후 대기 안내입니다.

로고는 `public/school-logo.png`에 넣고 `schoolLogo: './school-logo.png'`로 설정합니다. 인증서 로고는 같은 출처의 이미지 또는 PNG/JPEG/WebP 데이터 이미지만 지원합니다. 로고가 없거나 불러오지 못하면 로고 없이 발급합니다. 인증서는 1080×1440 PNG로 저장합니다.

## 기록과 운영

브라우저 `localStorage`에 진행 상황·설정·순위를 저장합니다. **다른 기기나 다른 브라우저와 순위를 공유하지 않습니다.** 비공개 창, 사이트 데이터 삭제, 저장 제한에 따라 기록이 사라지거나 저장되지 않을 수 있습니다. 이름은 실명 대신 닉네임을 사용하세요.

순위는 가장 최근 기록 500개를 보관하며, 화면에서는 한국 날짜(Asia/Seoul)의 기록을 점수 내림차순으로 표시합니다. 동점은 먼저 기록한 참가자가 앞섭니다. 사용자가 브라우저 데이터를 직접 바꿀 수 있으므로 엄격한 대회용 점수 인증 기능은 아닙니다.

주소 뒤에 `?admin=true`를 붙이면 음량·축제 모드·오늘 기록 초기화·전체 기록 초기화 메뉴가 열립니다. 이 메뉴는 **로그인이나 관리자 보안 기능이 아닙니다.** 기록 삭제에는 화면 확인 단계가 있습니다. 상세 부스 운영은 `FESTIVAL_GUIDE.md`를 참고하세요.
